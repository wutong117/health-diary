# 健康日记 · 本地减肥记录（PWA）

一个**完全本地**的减肥记录应用：1666 条中国食物成分数据、40 种减重饮食方法、体重趋势、每周复盘与自动调参。
**数据只存在你自己的设备上，不上传任何服务器**（这个网站只托管代码，不接收、不存储你的记录）。

## 手机上安装（推荐）

- **安卓 Chrome**：打开下面的网址 → 右上角 ⋮ → **「安装应用」**
- **iPhone Safari**（必须 Safari）：打开网址 → 分享 → **「添加到主屏幕」**

安装后是全屏独立窗口、可离线使用；数据保存在手机本机。

## 功能一览

**每日记录**：顶部「今日计划提示条」（预算/已摄入/还可以吃/蛋白质达标、餐次进度、断食窗口实时状态、当前方案）；热量与饮水数字**可直接改**；三大营养素实际值与目标值都可直接改（改比例↔改克数双向联动）；基础代谢估算；按餐次的饮食记录；饮水/体重/休息。

**计划**
- **40 种减重饮食方法**，分 7 组（热量缺口 / 宏量调整 / 时间限制 / 膳食模式 / 商业方案 / 行为方法 / 其他），支持分组筛选与中英文搜索
- 每种都写明 **机制**（为什么能减重）、**怎么吃**（具体内容）、**要记录什么**、**证据强弱与参考链接**、**禁忌人群**、**常见误区**；需要医学监督的方案会标红并二次确认
- 采用方案会自动算热量预算（TDEE − 缺口），并按方案的 g/kg 把蛋白质目标换算成准确比例
- **预算与护栏**：热量安全下限（男 1500 / 女 1200 千卡）可开关
- 餐次热量分配、16:8 等断食窗口计时、3 套运动计划（按 MET 算消耗）

**复盘**（每 1–2 周一次）
- 用最近 14 天的平均摄入 + 体重趋势变化**反推你实际的 TDEE**，给出新的热量预算建议
- 必须点确认才生效，三种选择（采用/保持/手动）都写入调整历史
- 三重护栏：单次调整 ±15%、记录完整度 <80% 不调参、连续 3 周趋势不降才判平台期

**体重趋势**
- 30 天曲线（绿色粗线 = 7 日移动平均、浅点 = 每日实测、橙虚线 = 目标、粉竖条 = 经期）
- BMI、腰高比、围度法体脂率、**5% / 10% / 15% 里程碑**、达成日期估算

## 数据与备份

- 存储：优先 IndexedDB，同时写一份 localStorage 镜像，两边按时间戳取较新的
- 换浏览器或清理数据前，请用「设置与说明 → 导出 JSON 备份」
- 从旧版（health-diary-v1 / v2）首次打开会自动迁移，旧数据保留不动

## 本地运行（可选）

直接双击 `index.html` 即可使用（功能完整，只是不能"安装"与离线缓存）。
想在电脑上获得可安装版本，用仓库里的 `serve.py`：

```bash
python serve.py            # http://127.0.0.1:8765/index.html
```

> 为什么要用它而不是 `python -m http.server`：Windows 注册表常把 `.js` 识别成 `text/plain`，
> Chrome 会因此拒绝注册 Service Worker（离线与安装都会失效），`serve.py` 显式指定了正确的 MIME 类型。
> GitHub Pages 会自动给出正确的 MIME，所以线上不需要它。
