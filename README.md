# 健康日记 · 本地减肥记录（PWA）

数据全部保存在你自己的设备上，不上传任何服务器。

## 怎么用

**方式一：直接双击 `index.html`**（最简单）
浏览器直接打开就能用，功能完整（含 1666 条食物库、记录、目标、基础代谢计算）。
局限：不能"安装到桌面"，也没有离线缓存——但数据一样会保存在本机。

**方式二：本地服务器（推荐在电脑上用）**
```bash
python serve.py            # 自动打开 http://127.0.0.1:8765/index.html
python serve.py --lan      # 允许手机在同一 WiFi 下访问
```
用 `serve.py` 而不是 `python -m http.server` 的原因：Windows 注册表常把 `.js`
识别成 `text/plain`，Chrome 会因此拒绝注册 Service Worker（离线与安装都会失效），
`serve.py` 显式指定了正确的 MIME 类型。

在 `http://127.0.0.1:8765/` 下打开后，Edge/Chrome 地址栏会出现"安装"图标，可装成独立窗口应用。

**方式三：托管到 https（手机装到桌面）**
把本文件夹整体上传到任意静态托管（GitHub Pages / Cloudflare Pages 等），手机上用
Chrome 打开 → 菜单 → "添加到主屏幕"。托管上只有代码，没有你的任何记录数据。
注意：手机通过局域网 IP（http://192.168.x.x）访问时不是安全上下文，无法安装 PWA。

## 功能

**每日记录**：顶部一条**今日计划提示**（预算/已摄入/还可以吃/蛋白质达标、餐次进度、断食窗口实时状态、当前方案），下面依次是热量/饮水直接改、三大营养素分配、目标设置、基础代谢估算、按餐次的饮食记录、饮水/体重/休息。

**计划**
- **40 种减重饮食方法**（`diet-library.js`），分 7 组：热量缺口 5、宏量调整 8、时间限制 6、膳食模式 9、商业方案 5、行为方法 2、其他 5。支持按组筛选与中英文搜索
- 每种方法都写清 **机制**（为什么能减重）、**怎么吃**（具体内容）、**要记录什么**、比例（若规定）、**证据强弱 + 参考链接**、**注意/禁忌**、**常见误区**；需要医学监督的方法（VLCD、PSMF、Optifast、GLP-1）会标红并二次确认
- 采用方案会**自动算热量预算**（TDEE − 缺口），并按方案的 g/kg 把蛋白质目标换算成比例，三项精确合计 100%；不规定比例的方法（WW、Noom、直觉饮食等）只做标记与说明，不动你的目标
- **预算与护栏**：可开关热量安全下限（男 1500 / 女 1200 千卡）。关掉后「采用方案」「用目标算预算」「每周复盘」都不再兜底，可低于 1200 千卡（界面会提示风险）
- **餐次热量分配**：早/午/晚/加餐百分比 → 每餐目标千卡 + 当日实际进度条
- **断食计时**（参考 [SoloForge](https://github.com/kirilan/SoloForge) 的方案划分）：16:8 / 18:6 / 20:4 / OMAD / 36 小时 / 隔日断食 / 5:2 / 自定义目标小时数；「开始断食→结束断食」自动记录时长，实时显示已断食时长、进度条、还差多久、预计达成时间；最近 7 天次数/平均时长/最长一次统计；断食记录可删除
- **运动计划**：3 套（久坐初学者 / 上班族 / 进阶加速）+ 本周每日安排，今天高亮并可一键"记录完成"，按 MET × 体重 × 时长算消耗

**食物库（新增包装与品牌食品）**
- **中国食物成分表 1666 条**（每 100 克）+ **包装食品 474 条**（Open Food Facts 中国区，每 100 克/ml）+ **中国品牌食品 270 条**（health-coach，多为"每份"，如奶茶/咖啡/便利店食品），合计 **2410 条、70 个分类**
- **条码查询**：输入包装上的条码 → 先查本地内置数据（离线可用），没有再联网查 Open Food Facts，查到的结果**缓存到本机**（以后离线也能用）
- **两种计量单位**：中国食物成分表和包装食品按「每 100 克/毫升」记录（填食用量），品牌食品按「每份」记录（填份数，如"2 大杯"）

**复盘**（每 1–2 周来一次）
- 用最近 14 天的**平均摄入 + 体重趋势变化**反推你**实际**的 TDEE（1 kg 体脂 ≈ 7700 千卡），再给出新的热量预算建议
- 明确列出依据（平均摄入、趋势变化、反推 TDEE、限幅/下限提示）与平台期判断
- **必须你点确认才生效**：采用建议 / 保持当前 / 手动设置，三种选择都会写进「调整历史」
- 最近 7 天记录情况一目了然；记录完整度低于 80% 时不调参，只提示补记录
- 三重护栏：单次调整 ±15%、完整度 <80% 不调参、连续 3 周趋势不降才算平台期

**体重趋势**
- 顶部直接输入今日体重，一键记录
- 30 天曲线：绿色粗线是 **7 日移动平均**（看趋势），浅点是每日实测（看波动），橙色虚线是目标体重，粉色竖条是经期标记
- 概览：当前体重、7 日移动平均、近 7 天变化、累计变化
- 里程碑：自动生成 **5% / 10% / 15%** 三档（《中国超重/肥胖症诊疗指南（2024）》的目标口径）加自定义目标，带完成进度
- 达成日期估算；「用目标算热量预算」按 TDEE − 缺口直接设好每日热量目标
- 围度（腰围/臀围/颈围）→ BMI、腰高比（≥0.5 提示风险）、美国海军公式体脂率
- 经期标记：曲线上直接看出水分波动，自动按"连续标记算一次"计算周期

**设置与说明**：导出/导入 JSON 备份、清空数据、数据来源与公式说明。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 界面结构（含全部样式） |
| `app.js` | 应用逻辑：记录、目标、食物库搜索、直接调整、方案采用、断食、复盘、导入导出 |
| `plans.js` | 能量与计划引擎：BMR/TDEE、热量预算（含可选安全下限）、体重趋势、周复盘与自动调参、MET 运动表、运动计划模板 |
| `diet-library.js` | **40 种减重饮食方法**：机制、具体内容、需记录项、证据与链接、禁忌、常见误区 |
| `food-db.js` | 中国食物成分表（1666 条，每 100 克） |
| `food-extra.js` | 包装食品（Open Food Facts 中国区 474 条，含条码）+ 中国品牌食品（health-coach 270 条，多为每份） |
| `sw.js` | Service Worker：离线缓存应用外壳（仅 http/https 生效） |
| `manifest.webmanifest` | PWA 清单：名称、图标、独立窗口 |
| `icons/` | 应用图标 |
| `serve.py` | 本地服务器 |

## 数据与备份

- 存储：优先 IndexedDB，同时写一份 localStorage 镜像；两者都按时间戳取较新的那份，避免丢数据。
- 从旧版（`health-diary-v1` / `health-diary-v2`）首次打开时自动迁移，旧数据保留不动。
- 换浏览器或清理浏览器数据前，请用「设置与说明 → 导出 JSON 备份」保存一份。

## 食物数据来源

**中国食物成分表**：[Sanotsu/china-food-composition-data](https://github.com/Sanotsu/china-food-composition-data)
（《中国食物成分表标准版（第 6 版）》"能量和食物一般营养成分"部分，共 1677 条，
本项目取其中 1666 条可用记录），营养值为每 100 克可食部。

**包装食品**：[Open Food Facts](https://world.openfoodfacts.org)（中国区 474 条，每 100g/ml，含条码）。
**数据库许可 ODbL 1.0，内容许可 DbCL 1.0**——使用或再分发这些数据时需保留署名并以相同许可共享。
你在应用里扫码查到的产品也会缓存到本机，同样适用该许可。

**中国品牌食品**：[H1an1/health-coach](https://github.com/H1an1/health-coach)（**MIT License**）
的 `references/cn-brands.md`，多为"每份"数值（大杯/中杯/罐等）。

参考项目：[Sanotsu/free-fitness](https://github.com/Sanotsu/free-fitness)、
[wger](https://github.com/wger-project/wger)、
[kirilan/SoloForge](https://github.com/kirilan/SoloForge)（断食方案划分）、
[statbench](https://github.com/tiffellio/statbench)。

## 免责声明

所有数值（BMR、TDEE、热量预算、运动消耗、体脂估算）都是**估算**，用于自我记录与趋势观察，
不构成医疗建议。孕哺期、进食障碍史、糖尿病/肾病等慢性病，请在医生或营养师指导下减重。
